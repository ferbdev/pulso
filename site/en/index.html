No windows full of charts: just the numbers that tell you whether your PC is okay.

  • Real-time temperatures

    CPU, GPU and disks, color-coded green, yellow and red. Spot overheating before it becomes a problem.

  • CPU, GPU, RAM and disks

How it works

From click to widget on screen in under a minute.

  1. Click “Open widget”

    The first time, your browser downloads Pulso.exe automatically.

  2. Open the file

    If Windows warns you, click More info → Run anyway. Then confirm the administrator prompt and the widget appears in the corner of your screen.

  3. Done, next time too

    Pulso registers itself with Windows, so this page’s button opens the widget directly.

Frequently asked questions

Do I need to install Pulso?

No. Pulso is a single Pulso.exe file with everything bundled, .NET included. Just download and open it.

Why does it ask for administrator permission?

CPU temperature and clock can only be read with administrator access and the PawnIO driver, the same one used by LibreHardwareMonitor. If the driver is missing, Pulso offers to install it with one click.

Windows showed “Windows protected your PC”. Is it safe?

This SmartScreen warning appears for new programs that are not digitally signed yet. Pulso is open source and the executable is built automatically on GitHub from that code. Click More info → Run anyway.

Does it work with AMD Ryzen and Radeon cards?

Yes. Pulso uses LibreHardwareMonitor, which supports Intel and AMD CPUs and NVIDIA, AMD Radeon and Intel GPUs.

How do I close or configure the widget?

Right-click it: you’ll find “Always on top”, opacity, refresh interval, show disks and “Close”.
