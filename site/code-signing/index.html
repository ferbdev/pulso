Política de assinatura de código

O Pulso.exe distribuído no GitHub Releases é compilado automaticamente pelo GitHub Actions, a partir do código-fonte público deste repositório, pelo workflow release.yml. Nenhum binário é compilado ou enviado manualmente.

Papéis

  • Committers e revisores: @ferbdev
  • Aprovadores (autorizam a assinatura de cada versão): @ferbdev

Privacidade

Este programa não transfere nenhuma informação para outros sistemas em rede, a menos que isso seja solicitado especificamente pelo usuário ou pela pessoa que o instala ou opera.

A única conexão de rede que o Pulso faz é quando o usuário clica em Instalar driver: nesse momento ele executa winget install namazso.PawnIO, que baixa o driver PawnIO do repositório oficial do winget. Os sensores são lidos localmente com o LibreHardwareMonitor (MPL-2.0). As configurações ficam apenas no computador, em %AppData%\Pulso.

Code signing policy

The Pulso.exe published on GitHub Releases is built automatically by GitHub Actions from this repository's public source code, using the release.yml workflow. No binary is built or uploaded by hand.

Team roles

Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

The only network connection Pulso makes is when the user clicks Install driver: it then runs winget install namazso.PawnIO, which downloads the PawnIO driver from the official winget repository. Sensors are read locally with LibreHardwareMonitor (MPL-2.0). Settings are stored only on the computer, in %AppData%\Pulso.
